# שילה — לוח עבודות

אפליקציית ניהול עבודות עיצוב ומיתוג לאירועים (קוליסות, שטיחים, שלטי כאפות ועוד).
Vite + React, עברית RTL, PWA. מערכת עיצוב `.sh` (פלטה, גופנים Secular One / Heebo / Azeret Mono).

## מטרה
כלי עבודה יומיומי למנהל: לראות את כל העבודות הפעילות, הסטטוס שלהן ומה דחוף — במקום לנהל בראש/וואטסאפ.
בהמשך: מוצר שאפשר למכור לבתי הפקה אחרים בתחום.

## דרך מדורגת
- **שלב א׳ (הנוכחי):** frontend מלא עם נתוני דמו — לוח עבודות, לוח שנה, כרטיס עבודה. ללא מסד נתונים.
- **שלב ב׳:** חיבור Supabase — נתונים אמיתיים, כניסה, שמירה.
- **שלב ג׳:** רב־דיירים (כל עסק עם הנתונים שלו) — לקראת מכירה.

## פיתוח
```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה ל-dist/
npm run preview  # תצוגה מקדימה של הבנייה
```

## מבנה
- `src/data.js` — סטטוסים, נתוני דמו, עזרי תאריך. **כאן יתחבר Supabase בשלב ב׳.**
- `src/index.css` — מערכת העיצוב `.sh`.
- `src/components/` — Header, Board (לוח + סרגל סיכום + סינון), Calendar, JobDetail (פאנל צד + קידום סטטוס), ui (תגים, placeholder תמונה).

צינור הסטטוסים: `פנייה → עיצוב → אישור לקוח → בהפקה → מוכן → הותקן`.
