## רעיונות ארכיטקטוניים ששווה לאמץ

1. **מנוע שמייצר קוליסה ממידה** — `generateKulisa({width,height})` מחזיר את כל
   החלקים לבד. אצלנו המשתמש מקליד נוסחאות ידנית לכל חלק.
2. **רכיב מול מכלול** — גיבן הוא Component אחד עם שני Members. אצלנו אין ייצוג כזה.
3. **היררכיית קודי חלקים** — `W1` → `W1-K1` → `W1-K1-V1` / `W1-K1-G1-M1`.
4. **מנוע חלוקת קיר** — קלט "קיר 540×240", פלט 2–3 חלופות חלוקה לקוליסות עם ניקוד
   (פחות קוליסות / סימטריה / פחות מידות חריגות). אין לנו שום דבר כזה.
5. **סיווג כל כלל**: `verified` / `preference` / `missing` — ולא להציג העדפה כחוק.
6. **אימות מידות** — חסימת 0, שלילי, NaN וחריגה מהמקסימום.
7. **חישוב מחדש בשינוי חוקים** — `rulesVersion` על כל קוליסה שמורה.

## מה אצלנו טוב יותר (לא לוותר עליו)
- 3D אמיתי עם גרירת חלקים, הצמדה וקווי עזר — אצלם 3D הוא תצוגה בלבד.
- חלקים חופשיים עם נוסחאות — מודלים גם שטיח, שלט והדפסה, לא רק קוליסה.
- אופטימיזציית חיתוך **שרצה בפועל** ומחזירה קורות ופחת. אצלם היא חסומה עד
  שיוגדר Kerf.
- דף שרטוט A4 להדפסה, כולל טיפול ב‑bidi של מספרים.
- שילוב מלא בעסק: עבודות, לקוחות, מלאי, הצעות מחיר, משמרות.
- עובד בפועל אצל הבוס.

## מה כבר מיושם אצלנו (v0.25.0)

- `src/designer/rules.js` — `VERTICAL_FACE_CM = 2` מסומן `verified`, `innerWidth(120) === 116`.
  אימות מידות: אפס/שלילי/NaN חוסמים, חריגה מ‑150×300 מזהירה.
- `src/designer/kulisa.js` — מחולל מסגרת ממידה. `defaultFrameMaterial` בוחר חומר
  שמקיים את הכלל המאושר, ולא את הפריט הראשון במלאי. חומר חורג עובד עם אזהרה.
- תוקן באג: חלק עם נוסחה שבורה קיבל בשקט אורך 8 ס״מ ונכנס כך לרשימת החיתוך
  **ולדף השרטוט של הנגר**. עכשיו הוא מוחרג ומסומן.

### עודכן 13.9.2026
- **מקסימום 3 מטר × 1.5 מטר** — אושר, `LIMITS.status = verified`.
- **2 גיבנים בכל קוליסה**, כל אחד משתי לטות ⇒ 4 לטות באורך רוחב−4.
  אושר ישירות משי, מוצהר כ-`GIBEN` ב-`rules.js`. ברירת המחדל במחולל.

  האופטימייזר בוחר את האורך שקונה הכי פחות עץ במקום להניח 300.
